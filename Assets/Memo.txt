	1. Mesh
		- 3D 오브젝트의 모양을 정의하는 데이터
		- 삼각형 면들로 구성되어있다.
		
		1) Vertex(정점)
			- 3D 공간상의 점들. 오브젝트의 형태를 정의하는 가장 기본 단위.

		2) Triangle(삼각형)
			- 정점 3개를 연결하여 하나의 면을 구성
	
	2. Material
		- 3D 오브젝트의 표면이 어떻게 보일지를 정의하는 데이터
		- EX) 빛을 어떻게 반사할지, 색상은 어떠한지, 질감은 어떠한지 등을 결정.

	=> Mesh는 모양, Material은 표면 색상을 담당

	3. Shader
		- 3D 오브젝트의 표면이 어떻게 보일지 계산하는 GPU 프로그램
		- Material이 그려지는 방식을 정의한다.

	-> Shader는 클래스, Material은 객체에 비유할 수 있다.
		- Shader는 어떤 방식으로 Rendering할지(화면에 그릴지) 정의하는 설계도
		- Material은 Shader를 기반으로 설정값들을 구제화한 실제 사용 데이터

	4. Texture
		- 3D 모델의 표면에 입히는 2D 이미지 데이터
		- Material을 통해 적용할 수 있음.

	-> 3D 오브젝트의 겉 포장지
	   
	5. 3D 모델
		- 3차원 공간에서 보이는 오브젝트의 형태와 외형을 정의한 데이터 집합
		- 게임의 입체적인 대상들을 일반적으로 모델이라 부른다.

	-> Mesh와 Material(Texture + Shader)이 함께 작동하여 3D 모델을 시각화함.

	간단하게 표현할 경우
	Mesh : 모양
	Material : 표면
	Texture : 무늬
	Shader : Rendering 코드

		- 최적화 기법
		- 자주 사용하는 오브젝트를 매번 생성/삭제 하지 않고 미리 생성해 놓고 활성화(Game Scene)/비활성화(Pool)	 하여 최적화를 추구하는 기법

	Particle System
		Emission : Rate over Time을 올리면 Particle이 더 많이 생김
		Shape : 방출되는 모양을 바꿈 -> Particle의 모양을 바꾸는 것이 아님
				- Mesh로 바꿔서 원하는 모양으로 나오게 할 수도 있음
		Start Delay : Random Between Two Constants로 바꾸면 각 Particle의 속도를 다르게 설정할 수도 있음
		Limit Velocity Over LifeTime : Particle들으 점점 천천히 / 빠르게 바꿀 수도 있음

	Project Settings -> Editor -> Sprite Packer -> Mode (Sprite Atlas) : 개별 이미지 파일을 하나의 이미지 파일로 만듦
		- 간단한 최적화 방법
		- 개별 이미지를 하나씩 불러온다면 하나씩 추가할 때마다 Batches가 증가하므로 개별 이미지 파일을 모아둔 이미지 파일 하나만 불러오는 방법을 사용해 최적화
		- 어차피 하나의 이미지 파일을 가져올 때 압축 하므로 모든 이미지들의 Compression은 None으로 설정하면 오류 안뜸
